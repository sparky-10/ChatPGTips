# ChatPGTips

Python class to vaguely/randomly answer questions in an absolutely not intelligent PG Tips themed way.

Inspired by:
* MATLAB 'why'
* ChatGPT et al.
* PG Tips

## Try

Interact with a working online version [here](https://sparky-10.github.io/code/pyscript-examples/code-in-my-console/).

## Usage

Import and ask a question:

```
from chatPGTips import chatPGTips            # Import
myMonkey = chatPGTips()                      # Init
myMonkey.ask("What is the answer monkey?")   # Ask a question!
```

Additional class methods include:

```
myMonkey.who()
myMonkey.what()
myMonkey.where()
myMonkey.why()
myMonkey.when()
myMonkey.how()
myMonkey.decide()
myMonkey.surpriseMe()
```
